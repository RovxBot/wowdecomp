# Original StatusBar widgets

This package selects original 12340 `CSimpleStatusBar` range/value callbacks,
horizontal/vertical fill geometry, color/rotation, texture regions and Lua/XML
factory on the native Frame owner. Pooled storage preserves native alignment;
widgets close before Scripts/images/renderer/Fonts and lower owners. Original
Windows bodies remain selected and its factory moves into the shared factory file.

Native setters reject nonfinite values, invalid raw orientation/layer indices,
foreign owners and changes during batch collection. Texture replacement requires
structural admission, canonical Lua objects and regions from this Frame or no
Frame. The old region survives incoming anchor installation. Rotation may be set
before a texture exists. Fill geometry invalidates when native layout changes size.
Value/color updates remain available in guarded callbacks; texture replacement
and hierarchy mutation reject there. Original range clamping and callback order
are retained. No donor imports, game data or server policy changes.

The hierarchy fixture checks pooled growth/reuse, Lua/XML inheritance and callback
arguments, clamping/equal ranges, horizontal/vertical/zero fill, resize restoration,
texture replacement/canonical ownership, rotation, owner/collection/callback guards,
stale tables and complete teardown. Original-data mode uses the original loading
bar image and UI shaders with unchanged archive authentication/selective MD5 policy.
That fill composition and its placement are authored; complete signed ordered
GlueXML and its full post-creation digest gate remain open. Physical input, native
login/authentication and gameplay are not established by widget fixtures.

All compilation and CTest run in GitHub Actions. Downloaded, hash-verified packages
can run against the read-only clean installation with external settings/cache.
Hosted and GPU qualification identities will be recorded after checks complete.
Slider/ScrollFrame/model and remaining widget consumers, full GlueXML, portable
transport/authentication and interactive user sign-in still gate M3.
