# Original base Frame XML factories and retained templates

This package connects original 12340 base Frame creation to the native pool,
hierarchy and Lua owners. `Frame::Native::Scripts` installs the bounded FrameXML
registry and Lua global `CreateFrame`. It closes the registry and transferred
virtual XML nodes before metatables, Fonts/layout/XML/VM/device/context/queue.
All client and dependency compilation runs in GitHub Actions.

The selected surface includes named parents, `$parent` names, ordered template
inheritance, nested base Frames, title regions and FontString draw layers. Original
layout, font attributes, localized text/language processing and parent-key tables
feed the existing Gxu/Gx renderer. Original Windows-selected bodies stay intact;
scalar Frame XML helpers move unchanged into shared `RegionXML.cpp`.

Native virtual nodes transfer from their XML tree into the registry. They remain
alive after that tree closes. Acquisitions retain the original lock/taint rules;
exceptions unwind locks and taint nesting. Creation preflights bounded template
graphs (64 depth, 4096 visits), names, numeric attributes and selected XML children.
Missing/cyclic/incompatible templates, spoofed parents, occupied global names and
unavailable widgets report errors. Allocated objects unwind on failure, including
nested children whose explicit parent lies outside the new root. Parent/root
ownership and original class pools remain responsible for successful objects.

The first registry admits base `Frame` only. FontStrings use their qualified typed
pool from Layers. Texture/backdrop/animation/script/widget XML consumers remain
unavailable. This is not the full ordered TOC/Include/Script executor or the complete
post-creation signature gate. Existing original-key archive, registered member MD5
and before/after GlueFonts-subset InterfaceKey checks stay enabled.

The three-cycle hierarchy fixture now exercises XML nodes retained after tree
close, inherited and explicit parents, pooled Lua creation, localized language text,
layers/title/nested children, rendered text/exact repeats, cycle/missing/unsupported
rejection, acquisition failure cleanup, nested creation rollback, stale canonical
tables, traversal guards and pool/batch teardown. Its text and composition are
authored, with authored or original fonts/UI shaders. Hosted and downloaded GPU
qualification is pending for this implementation.

The next callers are texture regions, widget factories and actual nonempty Lua
handlers, followed by signed ordered GlueXML creation and its full second digest
comparison. Physical IME/edit-box/candidate acceptance, complete original login
rendering, portable transport/authentication and observed gameplay remain open.
The clean installation stays read-only; the user will sign in interactively when
native login is ready. Preserve historical evidence and server revision
discrepancies. M3 remains incomplete.
