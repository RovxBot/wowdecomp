## Definition and constant batch

Accept the completed batch together. It improves the source contracts needed for
later game integration without replacing the native runtime with legacy objects.
The inspected differences preserve the current values and data widths at the
reviewed use sites:

- Frame message insertion keeps TOP=0 and BOTTOM=1 and the existing Lua strings.
  Backdrop masks and layout recursion guards retain their bit positions.
- Gx clears retain color=1 and depth=2. World enable bits, frustum results 0/3
  and shadow checks keep the previous operations. This does not fix the recorded
  Windows OpenGL warped-scene failure or implement the native Gx device.
- Particle emitter discriminators stay 0..3. The named float constants retain
  the exact former literals `0.033333335f`, `0.001f` and `0.1f`; there is no
  acceleration or visual-quality claim.
- Input masks retain the current joystick and unidentified tracking bits. The
  focus mask `~INPUT_DIRECTION_KEYS_MASK` is the same uint32 mask as
  `0xFFFFF00F`. Idle thresholds stay signed 300,000/1,800,000 ms and drag distance
  stays `8.0f`.
- `CameraView` names the same distance/pitch/yaw triplets, with no virtual members
  or new payload fields. Dynamic `Component()` callers iterate indices 0..2;
  shake slots remain three. Wider Win32/layout and native full-game qualification
  is still unavailable.
- `WC_SEND_RESULT` preserves sent=0, queued=1 and error=2 in both Windows
  implementations. The return typing does not port IOCP or change framing,
  queue, callback or cancellation control flow.
- Archive/file kinds use explicit uint32 enums; ordinary kind values remain
  0..5. Legacy `SFileImpl` and native `Packages` remain separate interfaces.
- Reaction ranks remain 0..7, loot methods 0..4, current unit sound slots 0..13,
  name errors 0..16, cursor payloads 0..13 and handler priorities 0/1. Power
  kinds remain signed, including the health sentinel -2 and seven power slots.
  `GetPowerString` retains an unsigned bounds check so a negative sentinel is
  rejected. Forced-reaction decoding assigns a typed temporary only after the
  existing `CDataStore` read succeeds; failed reads still leave storage untouched.

The historical 0.5.3 names in follow-up commits are comments where they do not map
to current 12340 behavior. They must not become active packet values, event IDs,
sound selectors or layout bounds. Existing upstream OFFSET/VERIFY annotations
retain their provenance; this review does not renew every binary-verification
claim. The focused reference observations above are the actual new evidence.
